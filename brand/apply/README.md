# apply. — logo kit

The mark for apply.atriveo.com. A lowercase "apply" wordmark set in Playfair Display Bold, ending in a full stop. The full stop is the only accent: an application that is sent and done.

## Files

| File | Use |
| --- | --- |
| `apply-wordmark.svg` | Primary logo, ink on light backgrounds |
| `apply-wordmark-reversed.svg` | Primary logo on dark backgrounds (the console header and login) |
| `apply-wordmark-black.svg` / `-white.svg` | One-colour print, stamps, embossing |
| `apply-symbol.svg` (+ `-reversed`, `-black`) | The "a." symbol for square spaces such as avatars |
| `apply-symbol-small.svg` | Simplified symbol for 32px and below (favicons) |
| `apply-app-icon*.svg` | App icon on the ink tile: standard, full-bleed (iOS), maskable (Android) |
| `apply-mono-4e86ff.svg` | All-blue version for special uses only |
| `overview.png` | The whole kit on one sheet |

The site uses `src/apply/ApplyLogo.tsx`, which is the same outlines inline. Its letters follow `currentColor`. The web icons and `site.webmanifest` live in `apply-public/`.

## Colour

| Token | Hex | Role |
| --- | --- | --- |
| Ink | `#0a0c12` | Letters on light backgrounds; icon tile |
| Paper | `#f6f5f1` | Letters on dark backgrounds |
| Atriveo blue | `#4e86ff` | The full stop, always |

The full stop is always blue, except in the one-colour black and white versions.

## Clear space and size

- Keep clear space around the wordmark at least the height of the full stop on every side.
- Wordmark: no smaller than 16px tall (letter height) on screen, or 12mm wide in print.
- Symbol: use `apply-symbol-small.svg` at 32px and below. Its cut is simplified so it stays readable at 16px.

## Type

Playfair Display Bold (SIL Open Font License 1.1), converted to outlines. You don't need the font installed to use the logo. If you set other text next to the mark, use the site's UI sans, not Playfair.

## Don'ts

- Don't recolour the full stop, or add a second accent colour.
- Don't capitalise the word ("Apply.") or remove the full stop.
- Don't stretch, rotate, outline, add shadows or put it on busy photos.
- Don't retype the logo in a live font. Use the outlined files.

No trademark search has been done for this mark.
